# @0x33a/anti-zh_llm (`anti-zh-llm`)

去除前端 UI/UX 与中文产品文案中的 AI 味（`zh_llm` 腔调与 AI Slop 反模式）。适用于开发、重构和审查网页应用、桌面端应用（Electron / Tauri / Qt）、管理后台及交互文案。

## 核心涵盖范围

1. **产品文案去 AI 味**：移除自证式内部实现声明、删除空洞复读副标题、杜绝无宾语的裸动词按钮与主谓不明的状态缩写、清理调试残留。
2. **布局复用与空间层级**：同级视图强制复用顶栏与筛选骨架、紧凑排列工具栏、统一同行控件高度与堆叠间距、主工作区聚焦高频操作并将低频配置/高危操作分层收起。
3. **盒模型、圆角与热区边界**：防止悬停背景或左边框把圆角顶成直角、防止外层容器裁切卡片边框、确保行内按钮严格收敛在悬停热区内、禁止在自定义主题中混入未修饰的系统原生 `<select>`。
4. **状态流转与交互真实性**：缺失前置条件时直接引导、区分普通校验与系统异常、消除“复选框 + 反向默认下拉框”的双重冲突控件、请求失败严禁伪造为 `0 / 正常`、切页过渡严禁残留不可点的旧列表 DOM、后台刷新保留当前操作上下文、敏感详情默认只读并提供独立复制入口。
